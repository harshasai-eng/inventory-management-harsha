System Architecture

The two halves run as separate processes on separate ports and only ever talk over HTTP. Everything on the right — the FastAPI app and the dataset it serves — lives inside one Python process: mock_data.py reads the seven JSON files in server/data/ into plain Python lists a single time, at import, and every request afterward filters those lists directly. There is no query layer, no ORM, and no disk access per request.

02

Filter & Render Pipeline

Every view is driven by up to four filters — time period, warehouse, category, order status — surfaced once in FilterBar.vue and shared app-wide through the useFilters composable. Changing any of them re-runs the same six-step loop, whether the view is the dashboard, inventory table, or spending report.

Demo, not production. There's no database — every restart of uv run python main.py reloads the seven JSON files fresh, so nothing written during a session persists. useAuth.js hardcodes isAuthenticated = true and logout just fires an alert; no request on the backend checks a token. CORS is wide open (allow_origins=["*"]), which is fine for a local demo pointed at a public repo but would need locking down before this talked to anything real.
